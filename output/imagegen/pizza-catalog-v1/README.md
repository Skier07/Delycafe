# Пиццы Delycafe — полный комплект 4К

33 пиццы из раздела «Пицца» в backend/products.json, ID 58–90.

Для загрузки используйте папку **4k** или архив **delycafe-pizzas-4k.zip** рядом с ней. В архиве по одному JPG на каждую пиццу, все изображения 3840×3840 пикселей. Сопоставление имён файлов и товаров находится в CATALOG.txt. Других размеров в комплекте для загрузки нет.

Изображения созданы встроенным image_gen в утверждённом стиле: белый фон, мягкий свет и тень, почти верхний ракурс с небольшим наклоном, вся пицца в кадре. Три ранее утверждённых изображения сохранены. Для «Морской» использован состав, сообщённый пользователем: красная рыба, креветки, кальмары, авторский сливочный соус, сыр, оливки, зелень.

4К получено согласованным программным увеличением оригиналов 1254×1254 методом Lanczos. Это не нативная генерация 4К; увеличение не добавляет настоящих деталей. JPG экспортированы с качеством 95 и без цветовой субдискретизации. Генерированные оригиналы хранятся отдельно как рабочие исходники, в архив загрузки не входят.

## Загрузка

1. Открыть нужный товар в админке и загрузить соответствующий JPG.
2. Поставить новую фотографию первой в галерее: именно первая фотография становится обложкой каталога.
3. Сохранить товар и обновить каталог приложения.

В исходниках приложения уже настроен BoxFit.contain для пицц в каталоге и карточке товара — без обрезки краёв. Для этого поведения нужна сборка с внесёнными изменениями. На сервер изображения в этой задаче не загружались.

Составы: tools/catalog_overrides.json; недостающие — https://pizzaozersk.ru/pizza/?page=2; «Морская» — сообщение пользователя. «Мясная» создана по составу, поскольку её исходная ссылка была заглушкой.

Тексты запросов и данные рецептов: generation-plan.json и prompts/. Запросы трёх первоначально утверждённых изображений: approved-test-prompts.txt. Проверенные размеры и объёмы файлов: export-report.json.
